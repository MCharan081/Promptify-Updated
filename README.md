# Promptify-Updated
Promptify is a simple web application that helps users create, improve, edit, and save AI prompts for coding, writing, studying, and marketing. It uses AI API integration to generate and enhance prompts based on user input.

*Features->*
Create Prompts: Turn simple ideas into clear, detailed AI prompts.
Improve Prompts: Enhance existing prompts using AI.
API Key Integration: Connect to an AI API using an API key to generate and improve prompts.
Category Presets: Choose from Coding, Writing, Study, or Marketing.
Edit Easily: Modify saved prompts and generate improved results.
Save & Favorite: Save favorite prompts and access them later.
Dark & Light Mode: Switch between themes for a comfortable experience.

*Technologies Used->*
Backend: Python, Flask, SQLite3
Frontend: HTML, CSS, JavaScript
AI Integration: AI API key integration
Icons & Fonts: Font Awesome, Space Grotesk, JetBrains Mono
